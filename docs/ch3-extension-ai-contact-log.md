**AI：**

**用户：**

中断式输入和轮询式有什么区别

**AI：**

我给你的总结是：
- 轮询式：程序不断主动问“现在有没有输入”
- 中断式：硬件有输入时主动通知内核，再把字符放进缓冲区

在这次实现里：
- 轮询版：`input_try_getchar()` 直接查 UART
- 中断版：打开 UART 中断 + PLIC + 环形缓冲区，`input_try_getchar()` 从缓冲区取数据

**总结**

这次拓展实验真正落地的关键点有 4 个：

1. `ch3` 内核新增最小 `virtio-gpu` 支持  
2. syscall 扩展出 framebuffer 和非阻塞输入接口  
3. 用户态实现 `snake_fb`，只负责游戏逻辑与绘图命令  
4. 同一份用户态程序复用轮询输入和中断输入两条内核后端
